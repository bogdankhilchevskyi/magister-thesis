# Магістерська робота з освітніх наук

«Педагогічні умови підтримки навчальної мотивації здобувачів медичної освіти в умовах дистанційного навчання в період воєнного часу».

Чернетки [розділу 1](drafts/chapter_1.md) і [розділу 2](drafts/chapter_2.md) та [список джерел](drafts/bibliography.md) зберігаються в `drafts/`. [Робочий план](planning/approved_outline.md) визначає структуру рукопису. [Стан роботи](planning/progress.md) містить результат останнього етапу й наступне завдання. [Реєстр](research/literature_registry.csv) та [матриця доказів](research/evidence_matrix.md) пов’язують джерела з аргументацією.

Вихідні DOCX і PDF збережено в корені. Правила наступної сесії містяться в [AGENTS.md](AGENTS.md). Актуальні версії рукопису доступні в гілці `main`.
